# Vigil - AI Agent Monitoring

> Real-time failure detection for AI agents.

## What is Vigil?

Most companies building AI agents face the same problem: agents fail silently.
They hallucinate, loop, or drift — and nobody knows until a customer complains.

Vigil is a monitoring system built specifically for AI agents. Add one line of code,
and Vigil captures every AI call, tool use, and decision — then classifies exactly what went wrong.

## Features
- Automatic trace capture via OpenTelemetry
- Failure classifier (hallucination, loops, goal drift)
- Dashboard with filtering and run replay
